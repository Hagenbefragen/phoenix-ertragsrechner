# Phoenix Rent - Ertragsrechner (Premium Edition)

Ein hochmoderner, interaktiver Ertragsrechner für Elektroautos und Fahrzeug-Investments. 
Diese Software wurde speziell entwickelt, um komplexe Finanzszenarien (Barkauf, Leasing, Auto-Abo, Phoenix-Rent) mit Fokus auf Vehicle-to-Grid (V2G) und steuerlichen Unterschieden (DE/AT) visuell und benutzerfreundlich aufzuarbeiten.

### Du möchtest diesen Rechner auf deiner Website nutzen?
Wir bieten flexible Lizenzierungsmodelle für Unternehmen, Flottenbetreiber und Autohäuser an. 

**Mögliche Lizenzmodelle:**
- **Pay-per-Use (API / Widget):** Z.B. 0,05 € pro Aufruf oder Berechnung. (Ideal für Plattformen mit hoher Reichweite bei geringem Fixkosten-Risiko).
- **Monatliche Flatrate (SaaS):** Ein fester Betrag (z.B. 49 € - 99 € / Monat) für die unbegrenzte Nutzung des interaktiven Rechners als iframe-Integration auf deiner Website.
- **Enterprise Buyout / Whitelabel:** Einmaliger Kauf der Software inkl. Branding auf dein Unternehmen. (Das primäre Ziel ist ein Verkauf/Lizenzierung an **Phoenix Rent**).
